# SkoLab shared contracts

This directory contains language-neutral contracts shared by the web client,
Android client, Python backend and Go services. It is deliberately separate
from any one implementation language.

## Rules

1. The live FastAPI OpenAPI document remains the source of truth for HTTP
   routes and generated models.
2. Stable cross-runtime envelopes and event payloads may be defined here as
   JSON Schema and then consumed/generated by each language.
3. A contract change must include compatibility evidence for every affected
   client or service.
4. Do not put UI models, database models, provider-specific responses or
   business logic in this package.

## Current contracts

- `error-response.schema.json` describes the error envelope emitted by the
  FastAPI handlers and mirrored by the Go gateway.

Run `python scripts/verify_contracts.py` after changing this schema or its
producer. The same check runs in the path-scoped Contract compatibility
workflow.

The OpenAPI snapshot and regeneration instructions remain in
[`api-contracts/README.md`](../../api-contracts/README.md).

## Planned additions

- pagination and cursor envelopes;
- asynchronous job / `202 Accepted` status;
- feed and recommendation event payloads;
- collaboration presence and message events.

Each addition must have a producer, consumer, compatibility test and owner
before it is treated as a supported contract.
