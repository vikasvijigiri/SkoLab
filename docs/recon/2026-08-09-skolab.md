## What this repository is

SkoLab is a research-discovery and collaboration platform: it ingests author and
paper data from OpenAlex/arXiv, runs LLM pipelines over it (summarisation,
prediction, agent chat), and serves that to a Next.js web app and a Kotlin
Android app. Three runtimes back it — a Python FastAPI service doing the AI and
data work, a Go gateway in front of it, and Firebase for auth plus real-time
workspace collaboration.

Not a guess: confirmed from `README.md`, `AGENTS.md`, `decisions/`, and the code.

## Subsystem map

**`services/backend`** (102 files) — FastAPI. `app/main.py:368` builds the app;
`app/api/v1/router.py:16-29` aggregates 11 routers. The domain-slice pattern is
followed only in `app/domains/{quest,recommendation}/`; elsewhere endpoint
handlers orchestrate inline — `authors.py` 776 lines, `feed.py` 582. Two modules
dominate and are the refactor risk: `services/platform/pipeline_services.py`
(3166 lines) and `connectors.py` (1472). `app/repositories/author_repository.py`
is the only formal repository; most services hit `app/db/database.py` directly.
Outbound: OpenAlex, arXiv, OpenRouter LLMs, Postgres.

**`services/backend-go`** (19 files) — Gin gateway, and it does what
`decisions/0002` says: terminates auth/CORS/rate-limiting, serves hot-path reads
(authors, leaderboard, quests, websockets) directly, and reverse-proxies the rest
to Python via `main.go:108` `NoRoute`. Rate limit 120 req/s burst 30.

**`apps/web`** (87 files) — Next.js 16 App Router. Public routes plus an
auth-gated `(app)` group (`layout.tsx:9-33`). All backend calls go through
`src/lib/api/client.ts` to `NEXT_PUBLIC_API_BASE_URL`, default `localhost:8080` —
the **Go gateway**, not Python. Workspace collaboration bypasses the gateway
entirely and talks straight to Firestore (`lib/firebase/workspace.ts`). Tailwind
v4 CSS-first tokens in `globals.css`; **`shared/skolab-design-system` is not
referenced anywhere in this unit**, despite a skill and a compile step existing
for it.

**`apps/android-app`** (141 files) — Kotlin/Compose. `MainActivity.kt:374` holds a
single `NavHost` with ~35 routes. `network/ServerLocator.kt` resolves the backend
by mDNS discovery in dev, `BuildConfig.BASE_URL` in prod. DI is a hand-rolled
singleton locator. Only `com.company.skolab` exists on disk — the
`com.open.entropy` paths in git history belong to an older tree, not this unit.

**`scripts/` + `infrastructure/`** — ops, security, database and build helpers.
`scripts/database/*` is wired into a real test
(`services/backend/tests/test_data_quality.py:38-49`) — the only script-to-test
link in the repo. **No CI workflow references anything under `scripts/` or
`infrastructure/`.**
