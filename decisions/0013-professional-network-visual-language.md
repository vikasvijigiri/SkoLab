# 0013 - Professional Network Visual Language

**Date:** 2026-09-09  
**Status:** Accepted

## Context

The owner supplied a LinkedIn job-page reference and requested the same
interface, theme, and font treatment. SkoLab needs its own research content and
brand, but should adopt the reference's calm, credible professional-workspace
language.

## Decision

Make light mode the default. Use a warm-neutral page canvas, white bordered
panels, restrained professional blue (`#0a66c2`) for active navigation, links,
and the single primary action, Inter for readable content, a compact top bar,
and a centered two-column dashboard. Dark mode remains available as an explicit
user choice.

## Consequences

SkoLab retains its name, icons, data models, and functionality; no third-party
logos, copy, or proprietary assets are copied. New surfaces follow this visual
language unless a later design decision changes it. Both light and dark token
sets continue to be contrast-tested.
