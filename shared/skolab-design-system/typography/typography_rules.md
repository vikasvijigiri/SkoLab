# Skolab Typography Rules

## Type scale

| Style | Size | Weight | Color | Use for |
|---|---|---|---|---|
| Display | 32sp | 800 | text_primary | Hero numbers, splash screen values |
| H1 | 22sp | 700 | text_primary | Screen titles, section headers |
| H2 | 17sp | 700 | text_primary | Card titles, subsection headers |
| H3 | 14sp | 600 | text_primary | List item titles, field labels |
| Body | 13sp | 400 | text_secondary | Descriptions, body copy |
| Caption | 10sp | 500 | text_muted | Timestamps, meta, helper text |
| Micro | 8sp | 600 | text_muted | Chips, badges, tab labels (ALL CAPS) |

## Rules
1. Maximum 2 type styles on any single card.
2. Never use Display outside of hero blocks and analytics stat cards.
3. Body copy line height must be 1.5 — never tighter.
4. On color_bg_hero (#2D6BE4) surfaces: use OnPrimary for values, OnPrimarySub for labels.
5. Never set custom text colors inline — always reference a named style.
6. Letter spacing on Micro must remain 0.04 — tighter breaks readability at 8sp.
