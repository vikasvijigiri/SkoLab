# Design contract

`DESIGN.md` at the repository root is the authority for the `apps/web` visual
surface — tokens, type scale, spacing, components, motion, and the accessibility
floor. Read it before any web UI work. The Android client is a separate, flat
surface and is out of its scope. Supporting references live in `docs/design/`.

# Engineering references

`docs/ops/` holds curated, vetted external references (backend, frontend,
testing, security, observability, hosting, backend-as-a-service, mobile
builds) and this repo's own docs conventions. Consult the relevant file
before deciding an approach from the request text alone.
