# Capability layer

This repository uses the portable layer in `.claude/`. Read `.claude/workflow.md` for the execution policy and use the native skills, commands, and hooks registered by the active host.

# Design contract

`DESIGN.md` at the repository root is the authority for the `apps/web` visual
surface — tokens, type scale, spacing, components, motion, and the accessibility
floor. Read it before any web UI work. The Android client is a separate, flat
surface and is out of its scope.
